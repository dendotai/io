Scripts that record io's menu bar icon beside the Sound icon and measure both, frame by frame (issue #86). Compile each with `swiftc -O <file>.swift -o <name>`; run from a scratch folder, because they write PNG frames.

- `recdisplay X Y W H SECONDS OUTDIR`: records a region of one display (points, top-left origin; `DISPLAY_ID=2` picks a display other than the main one) at the display's refresh rate; writes `f<ms>.png` per distinct frame and `frames.txt`. A recording of a display whose content does not change can hang at the end: run it under `perl -e 'alarm 60; exec @ARGV' …`.
- `iconrun <recdisplay path> <outdir> [dry|-] <io.app path>`: opens the Sound menu with an Accessibility press (its open menu shows a menu bar a full-screen app hides), records, changes volume and mute through Core Audio and the output through io's Debug `pickOutput` default (the AirPods by the names in `AIRPODS_PRO` and `AIRPODS_MAX`), closes the menu, and restores volume and mute. `dry` opens the menu, records one second, and lists its rows: a static frame of the active display's bar, whose menu bar a full-screen app hides. The region, the display and which Sound item it presses (`.first` is the built-in display's, `.last` the Studio Display's) are constants near the top and the recorder lines.
- `harness/build.sh`, then `harness/harness <seconds> <outputUID>:<symbol>[:<variable>]…`: shows the real `MenuBarIconView` in a 32 × 22 pt window at the main display's bottom-left corner, plays each step that many seconds apart, and prints one line per distinct frame at the display's refresh rate: ms, total ink, ink box, ink centre (`DUMP=<dir>` writes the frames as PNGs; `WINDOW_H`, `HOST_Y`, `HOST_H` set the window's height and the button's frame in points). Each run takes seconds and needs no menu bar, so it settles a transition's shape, length, and any move before a recording beside the Sound icon; the status bar's pixel snapping differs from the window's, so a symbol's resting row is read in the bar.
- `centres <dir> <from ms> <to ms> <x0> <x1>`: per frame, one icon's total ink and ink-weighted centre (brightness above 0.35, so the Sound item's open-menu capsule is left out).
- `glyph <png> <x0> <x1>`: the ink box at half the brightest ink, two rows through it as `#/+/.`, the brightest value and the total ink: compares size, stroke and colour.
- `inkbox <dir> [runs]`: per frame, the ink boxes of both icons at fixed columns; `runs` lists the ink column runs of the first frame, to find where each icon sits.
- `pieces <symbol> [variable]`: the symbol's palette layers at 2x and their alpha against the whole symbol, to check that the pieces io animates add up to the symbol.
- `bands <dir> <x0-x1>…`: per frame PNG in a dump, the ink and box in each column band, to follow one layer of a symbol through a transition.
- `ink <pointSize|default>`: renders each Menu bar icon symbol at 2x off screen and prints its ink box, to pick a symbol configuration.
- `devs`: lists the audio outputs, the one in use marked with `*`.
- `sounditems`: lists the Sound item on each display with its frame.
